# Ciao, sono Gabriele Pierotti 👋

### Software Developer | Backend & Architecture Enthusiast

Mi definisco un artigiano del codice. Amo costruire sistemi dove la complessità tecnica viene celata da interfacce pulite e silenziose. Il mio approccio si basa sul **Design del Silenzio**: meno rumore visivo, più potenza logica.

---

## 🛠️ Cosa sto costruendo
Attualmente il mio focus principale è **[Vanitas Studios](https://github.com/Vanitas-Studios/VanitasStudios_WebSite)**, un CMS modulare progettato per la documentazione tecnica e il gaming.
- **Logica Ricorsiva:** Gestione gerarchica dei contenuti per una flessibilità infinita.
- **Data Integrity:** Implementazione di sistemi di Soft-Delete e Garbage Collection dei media.
- **UX Focus:** Interfacce distraction-free per massimizzare la produttività dell'editor.
- **Brand Identity**: [Clicca qui per scoprire la genesi del mio logo personale](LogoGenesis.md).

## 🚀 Competenze Tecniche
- **Backend:** C#, .NET Core, ASP.NET Web API, Entity Framework.
- **Database:** SQL Server (Progettazione schemi, ottimizzazione query).
- **Frontend:** JavaScript, CSS (Minimalist frameworks), HTML5.
- **Tools:** Git, GitHub Actions, Photoshop (per il design di supporto).

## 📖 La mia Filosofia
Credo fermamente che un buon software debba essere accompagnato da una documentazione eccellente. Per ogni mia repository troverai un file `DEVLOG.md` che narra le sfide, i fallimenti e le rianalisi che hanno portato al prodotto finale.
